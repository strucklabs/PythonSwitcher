PythonSwitcher
==============

Verwaltet mehrere Python- und Git-Versionen auf einem Windows-PC:
hinzufügen, entfernen und auswählen, welche Version verwendet wird.

Start
-----
PythonSwitcher.exe per Doppelklick starten. Eine Installation ist nicht nötig,
.NET muss nicht installiert sein.

Beim ersten Start sucht das Programm automatisch nach vorhandenen Versionen.

Bedienung
---------
- Aktivieren: Die gewählte Version wird künftig verwendet, wenn im Terminal
  "python", "pip" oder "git" eingegeben wird. Dazu stellt das Programm ihre
  Einträge in der Umgebungsvariablen PATH nach vorn. Alle anderen Einträge
  bleiben erhalten.
- Ordner hinzufügen: Eine Version aufnehmen, die nicht automatisch gefunden
  wurde.
- Herunterladen: Eine offizielle Version laden (Python von python.org,
  Git als PortableGit von GitHub). Prüfsumme und digitale Signatur werden
  vor dem Ausführen geprüft.
- Entfernen: Nimmt eine Version aus der Liste. Nur Versionen, die mit diesem
  Programm heruntergeladen wurden, können auf Wunsch auch gelöscht werden.

Gut zu wissen
-------------
- Änderungen gelten für Terminals und Programme, die danach gestartet werden.
  Bereits geöffnete Fenster behalten ihren bisherigen Stand.
- Windows liest zuerst den System-PATH (gilt für alle Benutzer), dann den
  Benutzer-PATH. Steht dort eine andere Version, fragt das Programm nach, ob
  auch der System-PATH geändert werden soll. Dafür sind Administratorrechte
  nötig.
- Vor jeder Änderung wird der bisherige PATH gesichert. Mit
  "Letzte PATH-Änderung rückgängig" lässt er sich wiederherstellen.

Daten und Sicherungen
---------------------
%LOCALAPPDATA%\PythonSwitcher
  einstellungen.json   Liste der Versionen
  Sicherungen\         gesicherte PATH-Werte (reine Textdateien)
  python\, git\        heruntergeladene Versionen
